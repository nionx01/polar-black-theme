# Changelog

All notable changes to the "Polar Black" extension will be documented in this file.

## [0.0.1] - [0.0.3] - 2026-02-15

### Added
- **Polar Black Default Color** - Muted syntax color theme on pure black background with white UI accent
- **Polar Black Vibrant Color** - Saturated/vivid syntax color theme variant with white UI accent
- **Polar Black Ice Color** - Muted syntax colors with frosty blue-white (`#B8DCE8`) UI accent
- Comprehensive file icon theme with hundreds of file type icons
- Context-aware folder icons (carbon + white variants)
- Custom product icon theme with 120+ UI icons in a dedicated font
- Full coverage of VS Code core icons (explorer, search, source control, debug, extensions, settings, terminal, etc.)
- GitLens integration icons
