# Changelog

All notable changes to the "Polar Black" extension will be documented in this file.

## [0.0.6] - 2026-03-12

### Added
- **Polar Black Cherry Blossom** - Sakura pink syntax and rose-tinted UI on pure black
- **Polar Black Light** - Full light mode variant with bright backgrounds and dark syntax
- **Polar Black Savanna** - Warm golden earth-tone syntax with amber UI accents
- **Polar Black Green Cactus** - Lush green syntax palette with emerald UI accents
- **Polar Black Less Black Smoke** - Softer dark gray background variant of Default
- **Polar Black Red** - Full crimson red syntax palette with red UI accents

### Changed
- **Polar Black Ice Color** - Now features unique icy blue-tint syntax colors (mint strings, frost types, steel functions) instead of sharing the Default palette
- Updated keywords and metadata for new themes

## [0.0.3] - [0.0.5] - 2026-02-15

### Added
- **Polar Black Default Color** - Muted syntax palette on pure black with white UI accent
- **Polar Black Vibrant Color** - Saturated vivid syntax variant
- **Polar Black Ice Color** - Frosty blue-white UI accent variant
- Comprehensive file icon theme with 1100+ file type icons
- Context-aware folder icons (carbon + white variants)
- Custom product icon theme with 200+ UI icons
- GitLens integration icons
- Inline color highlight extension feature

## [0.0.1] - 2026-02-01

### Initial Release
- First public release on VS Code Marketplace
